03 · The Problem SLIDE 03 / 10

Browser tabs have become an anxious external memory bank for 1B+ knowledge workers.

Engineers and researchers don't keep 42 browser tabs open for three weeks to read 5,000-word essays. We keep them open because 5 of those tabs contain a 3-line CLI flag, SQL snippet, or benchmark number we are afraid to lose.

❌ Why Current Solutions Fail

  • Bookmark & Tab Managers (OneTab, Pocket): Turn clutter in the tab bar into a static graveyard of links you still never read.
  • Single-Tab AI Chatbars (Copilot, ChatGPT Sidebars): Summarize one tab at a time, strip out CLI flags/code blocks, and cannot triage 40 tabs simultaneously.
  • Unverified LLM Wrappers: Hallucinate version numbers, invent flags, and provide zero calibrated confidence on whether a tab is safe to close.
  • Cognitive & RAM Tax: 40+ active Chromium renderers consume 4–8 GB of RAM and fragment deep engineering focus.

✅ What Knowledge Workers Actually Need

  • Calibrated Triage with Uncertainty Bounds: A statistical guarantee (`P10 / P50 / P90`) that closing a tab won't throw away critical reference material.
  • Section-Anchored Extraction: Exact `Section Heading — Fact` takeaways plus preserved copyable code blocks (`pre/code`).
  • Zero-Prompt & Topic-Focused Modes: Summarize every open tab immediately, or say a topic (e.g., "Japan travel" or "quiet laptop") and watch unrelated pages move aside.
  • Eyes-Free Executive Briefing: A 20-second spoken audio summary verified digit-by-digit against ground truth.

04 · The Solution & Dual-Lane Architecture SLIDE 04 / 10

Meet Folivora: Deterministic LLM-free triage + grounded open-weight AI polish.

Folivora decouples instant structural triage from background LLM synthesis—rendering interactive dossiers in ~1.3s warm (~30ms from the preset cache) while upgrading prose asynchronously behind strict mathematical verification gates.

STAGE 01 · CAPTURE

🌐 Browserbase CDP + Extension

Captures open window URLs via Manifest V3 Chrome Extension or opens live pages in Browserbase Cloud Chromium over raw CDP WebSockets.

STAGE 02 · SIEVE

📊 Prior Labs TabPFN v2

Scores 7 structural & intent features on CPU to predict calibrated P10 / P50 / P90 quantiles. Enforces P90 < 45 safety gate.

STAGE 03 · FAST LANE

⚡ Instant Dossier (Zero LLM)

Immediately renders sanitized section-anchored takeaways, copyable code blocks, reading time saved, and keep/close verdicts.

STAGE 04 · GROUNDED AI

💎 Gemma 4 + Gemini Flash Lite

Upgrades the spoken brief (check_output() digit gate) & polishes top 8 tab cards against bounded E#/C# evidence packs.

STAGE 05 · VOICE & TRACE

🎙️ ElevenLabs + Sentry

Scribe (scribe_v1) voice intent input (with immediate remote delete), Flash v2.5 spoken briefing, and scrubbed Sentry OpenTelemetry spans.

📖 Mode A: Summarize All Open Tabs (Default)

Click Summarize All with no prompt needed. Every valid tab is kept (`rated=False`) and distilled into a 30-second card with an overview, `Heading — Takeaway` bullets, and copyable code snippets.

🎯 Mode B: Topic Focus & Set-Aside Triage

Type or speak a topic (e.g., "Japan travel", "meal prep", or "Web development"). Folivora ranks matching tabs under Worth Your Time, surfaces a dedicated 🎯 Focused on "<Topic>" tab on each card, and moves unrelated pages to Set Aside — nothing in your browser is closed or touched.

07 · Defensible Technical Moat & Security SLIDE 07 / 10

Built for enterprise-grade privacy and zero-trust web ingestion.

Every external web page inspected by an AI browser agent is untrusted input. Folivora treats web DOMs as adversarial by default and isolates user sessions from end to end.

🔐 Multi-Layer Privacy & Isolation

  • Private Ephemeral Job Store: Custom user URLs are isolated in a per-job TTL/LRU store (15m expiry) and never written to shared caches or serialized back in raw API responses.
  • Transcribe-and-Forget Voice Privacy: Voice intents sent to ElevenLabs Scribe (scribe_v1) trigger an immediate remote DELETE /v1/speech-to-text/transcripts/{id} in a finally block.
  • SSRF & Network Hardening: Blocks RFC1918 private IPs, loopback, link-local metadata endpoints, and credentialed URLs on every redirect hop.

🔭 Observability & Cost Efficiency

  • Sentry OpenTelemetry GenAI Tracing: Tracks latency, token throughput, and estimated cost across browserbase.inspect_tabs, tabpfn.predict_quantiles, and gemma.digest spans.
  • Regex Secret Scrubber: Redacts api_key, tabpfn_token, and signingKey while preserving gen_ai.usage.input_tokens and output_tokens.
  • Sub-Cent Unit Economics: Pre-baked CPU TabPFN weights ($0 API cost per triage) + bounded evidence packs keep full 8-tab AI polish under $0.002 per batch.
