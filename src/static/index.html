Summarize Your Entire Browser Window in One Click

Install the lightweight Folivora extension for Chrome, Edge, or Brave to grab every open tab in your current window, put unused tabs to sleep so they stop using memory, or close unrelated tabs with one-click undo.

Download Extension (.zip)
  1. Unzip the downloaded file and open chrome://extensions (or edge://extensions).
  2. Turn on Developer mode in the top corner and click Load unpacked.
  3. Select the unzipped folder, then click the Folivora icon whenever your tabs pile up.
